# Morning Routine Timer

A focused, mobile-first timer that guides one morning routine step at a time.

## iPhone Installation

1. Open [Morning Routine Timer](https://elviselva.github.io/routine-timer/app/) in Safari.
2. Tap **Share**.
3. Tap **Add to Home Screen**.
4. Make sure **Open as Web App** is enabled, then tap **Add**.

The installed app works offline and requests that the screen stay awake while the routine is active.
